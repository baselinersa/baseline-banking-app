# 🏦 Baseline Banking App

## 📌 Overview
Baseline Banking App is a Python-based console banking simulation system designed to manage user accounts, transactions, and savings while providing AI-inspired spending insights.

The project combines **software development** and **data science concepts** to simulate real-world banking behavior and financial decision-making.

This app was built to strengthen my skills in **Python programming, data handling, logic design, and basic financial analytics**.

---

## 🚀 Features

### 🔐 Authentication
- PIN-based login system
- Forgot PIN functionality
- Change PIN option

### 💳 Account Management
- Main Account 💵
- Savings Account 💰
- Deposit and Withdraw (choose account)
- Fast transfers between Main ↔ Savings

### 📊 Transaction Tracking
- Full transaction history
- Time-stamped transactions (SA Time)
- Optional receipts after transactions
- Summary of the last 5 transactions

### 🤖 AI-Inspired Insights
- Spending analysis (deposits vs withdrawals)
- Warnings when spending exceeds saving
- Smart savings suggestions
- Conditional tips for large transactions

### 🎨 User Experience
- Clean console interface
- ANSI color-coded outputs
- Clear headings and structured menus

---

## 🧠 Data Science Concepts Used
- Data collection and storage
- Aggregation of financial data
